# 问道录 · 后续更新路线图（元婴篇及以后）

> 2026-10-22 立档。结丹六机制闭环后立项。
> 设计方法：取《凡人修仙传》的**情节结构与名场面节奏**当锚点，全部映射为本作架空设定（去原著化铁律），不搬名词、不抄段落。

## 0. 现状基线

- 境界：练气 13 层（index 0–12）+ 筑基 3 阶（13–15）+ 结丹 3 阶（16–18），**结丹后期为顶层**，元婴篇未开工。
- 地图章节：练气篇 / 筑基篇 / 结丹篇 / 碎星海篇（`data/worldmap.js`）。
- 刚闭环的结丹六机制：见闻录文本池、周天星斗大阵、阵营声望追杀令、傀儡混编军团、体修/法修道途、神识夺舍心魔。
- 现成地基可延伸：`insect.js`（灵虫）、`teleport_portal.js`（传送阵终局）、`endings.js`（多结局）、`sect.js`（宗门）、`mansion.js`/`cave2.js`（洞府）、`Faction`（三阵营）、`Chronicle`（见闻录池）。
